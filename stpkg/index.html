安装指南

直接在线安装

最简单的安装方式是使用我们提供的在线安装代码，步骤如下：

  1. 打开 Stata 软件
  2. 复制我们提供的安装代码
  3. 在 Stata 命令窗口中粘贴并运行代码
  4. 按照提示完成安装
net install package_name.pkg, from("https://tidyfriday.cn/stpkg/data/package_name") replace force

下载后安装

如果您无法在线安装，可以下载安装包后手动安装：

  1. 下载 ZIP 压缩包并解压到本地文件夹
  2. 打开 Stata 软件
  3. 使用以下代码，将路径替换为您的解压文件夹路径
  4. 按照提示完成安装
net install package_name.pkg, from("package_name.pkg 文件所在的完整文件夹路径") replace force
