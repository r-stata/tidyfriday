Color Palettes · 调色板选择

基于 ColorBrewer 魔改的配色选择工具，并集成了 R 语言
paletteer 包中的全部调色板。
支持来源切换、分组筛选、名称搜索、分页浏览，以及 HEX / RGB / CMYK 三种颜色格式与
ASE / GPL / JSON / CSS 多种导出。

特性

  • 数据来源：ColorBrewer 官方配色、自用（个人）调色板、R paletteer 全量调色板、colorspace 包的命名 HCL 调色板（paletteer 未收录），以及整理自 chinese-colors.heyfe.org 的中国传统色（按色相归为 10 个家族调色板，共 525 色）。打开时默认选中 awtools::a_palette。
  • 分组 / 包筛选：按 ColorBrewer 类型、自用分类、或 R 包名分组，支持关键词过滤。
  • 搜索：按调色板名称实时过滤。
  • 分页：单页 24 个，应对 paletteer 的 2800+ 调色板。
  • 双预览：右侧上方为 ColorBrewer 风格的美国郡县地图（choropleth），下方为柱状图 / 色块预览。地图按当前调色板着色（颜色数 > 12 或 = 2 时自动重采样到地图支持的 3–12 层）。
  • 多格式预览：HEX / RGB / CMYK 一键切换，点击颜色值即可复制。
  • 导出：复制 HEX / JSON / CSS，下载 Adobe ASE、GIMP GPL；另支持
    • 复制 R 语言用：c("#rrggbb", "#rrggbb", ...)
    • 复制 Stata 用："r g b" "r g b" ...（空格分隔的 RGB 值，带引号）
  • 零运行时依赖：纯原生 JS，数据以 JS 全局变量内嵌，可直接 file:// 打开，无需构建或服务器。

目录结构

colors/
├── index.html              # 站点入口
├── assets/
│   ├── css/style.css       # 样式
│   ├── js/app.js           # 前端逻辑（原生 JS，无依赖）
│   └── data/               # 生成的数据层（JS 全局变量）
│       ├── colorbrewer.js  # window.COLORBREWER_DATA  (45)
│       ├── custom.js       # window.CUSTOM_DATA        (274)
│       ├── paletteer.js    # window.PALETTEER_DATA      (2868)
│       ├── colorspace.js    # window.COLORSPACE_DATA     (97, 来自 colorspace 包)
│       ├── chinese.js       # window.CHINESE_DATA        (525 色 / 10 个家族调色板)
│       └── map.js          # window.MAP_SVG             (内联的美国郡县地图)
├── scripts/
│   ├── build-paletteer.R   # 从 R 提取 paletteer 全量调色板 -> paletteer.raw.js
│   ├── build-colorspace.R  # 从 R colorspace 包提取命名 HCL 调色板 -> colorspace.raw.js
│   ├── build-chinese.py    # 从 chinese-colors.heyfe.org 抓取中国传统色 -> chinese.js
│   ├── build-data.js       # 归一化 + 采样，生成上面的 data/*.js
│   ├── build-map.js        # 把 legacy/map/map.svg 内联为 data/map.js
│   └── serve.js            # 零依赖静态服务器（可选）
└── legacy/                 # 原始魔改版本（归档，保留旧版链接）

本地运行

直接双击 index.html 即可（数据内嵌，无需服务器）。

如需通过 HTTP 访问：

npm run serve      # 或 npm start，默认 http://localhost:4173

数据构建（可选，仅更新调色板时需要）

npm run build:paletteer   # 运行 R 脚本，重新抓取 paletteer 全量调色板
npm run build:colorspace  # 运行 R 脚本，提取 colorspace 包的命名 HCL 调色板
npm run build:chinese     # 抓取 chinese-colors.heyfe.org 的传统色，生成 chinese.js
npm run build:data        # 归一化 + 采样，重新生成 data/*.js
npm run build:map         # 把 legacy/map/map.svg 内联为 data/map.js（地图预览用）

需要本机安装 R 及 paletteer、colorspace、jsonlite 包（前两者）。
build-paletteer.R / build-colorspace.R 必须在项目根目录运行（相对路径输出到 assets/data/）。
build-chinese.py 需要 Python 3 及网络访问（可用 --use-cache 复用本地缓存）。
