1998～2014 年工企业地理位置、所处区县、与秦岭淮河线距离、南北方数据（含 gqid 变量）

2021-07-24 1878 字 约 5 分钟 次阅读 数据资料 距离与边界上市公司

去年就给大家提供了一份 1998～2013 年工企业地理位置数据，但是那个时候的数据没有成体系，最近我们重新整理了工企、海关、污染、专利的数据，给每个数据生成一个 ID 变量用以标志观测值：

  1. 工企数据里面我们生成了一个 gqid 变量；
  2. 海关数据里面我们生成了一个 hgid 变量；
  3. 污染数据里面我们生成了一个 wrid 变量；
  4. 专利数据里面也可以生成一个 zlid 变量（暂不提供）。

那么工企和海关匹配的结果里面就会有 gqid 和 hgid 变量；工企和污染匹配的结果里面就会有 gqid 和 wrid 变量；今天提供的工企地理位置数据里面也会有个 gqid 变量，这样就能很容易得到工企+海关+地理位置或者工企+污染+地理位置，甚至 工企+海关+污染+地理位置的联合匹配结果了！

此次分享的数据包含如下几份：

1. 1998~2013年工企业地理位置、与秦岭淮河线距离、南北方属性数据.dta（16.13GB）

这个数据包含了工企数据库的所有变量和经纬度数据，另外还有一些根据经纬度数据生成的变量：

  1. gqid：用于标志工企库的每个观测值（每个观测值的 gqid 值都是唯一的）；
  2. 经度：根据高德地图地理编码接口解析得到的经度（已经转成了 WGS84 坐标系）；
  3. 纬度：根据高德地图地理编码接口解析得到的纬度（已经转成了 WGS84 坐标系）；
  4. 县代码：根据上面的经纬度判断所处的区县代码；
  5. 县：根据上面的经纬度判断所处的区县；
  6. 省代码：根据上面的经纬度判断所处的省份代码；
  7. 省：根据上面的经纬度判断所处的省份；
  8. 市代码：根据上面的经纬度判断所处的城市代码；
  9. 市：根据上面的经纬度判断所处的城市；
  10. 是否和省界接触：所在的区县是否和省界相接触；
  11. 是否和海岸线接触：所在的区县是否和海岸线相接触；
  12. 是否和陆地国界线接触：所在的区县是否和陆地国界线相接触；
  13. 是否为内部县：所在的区县是否同时不和省界、国界、海岸线相接触；
  14. 与秦岭淮河线的距离：距离秦岭-淮河线的距离；
  15. 北方或南方：根据经纬度判断的所处位置是北方还是南方。

2. 1998~2013年工企业地理位置、与秦岭淮河线距离、南北方属性数据（分年）

由于上面的数据太大了，所以我们把数据拆分成了逐年的（每年一个文件），这样即使电脑内存不大也可以逐一处理了。

4. 2014 年的数据

由于 2014 年的数据来源不同，也没有企业匹配唯一标识码变量，所以就没有合并，有需要的小伙伴可以自行选择使用。

注意事项

  1. 经纬度是根据省自治区直辖市 + 地区市州盟 + 县区市旗 + 乡镇 + 街道办事处 + 企业名称生成的地址变量再通过高德地图地理编码接口生成的，可能存在错误，不过也没有很好的判断是否错误的方法（一种粗略的方法是比较数据里面的省 和 省自治区直辖市 变量，如果不同就认为是错误的）；
  2. 高德地图地理编码接口返回的是 GCJ02 坐标系的坐标，为了方便大家使用已经转换成了 WGS84 坐标；
  3. 高德地图地理编码接口解析经纬度的方法是如果没有在地址库里面搜索到某个地点的名称就返回上一级地址的经纬度。例如，没有找到广东省广州市珠江新城的坐标，那么就返回广东省广州市的坐标。这也就导致了数据里面很多不是一家企业的经纬度却相同（这些也可以认为是解析错误）；
  4. 由于工企数据库是 1998～2014 年的，里面的地址自然也是 1998～2014 年的，而高德地图接口返回的经纬度是最新地址的，这也可能导致经纬度错误（这个应该问题不大，毕竟公司搬家的不多。且也没有什么好的办法了）；

距离秦岭淮河的距离

秦岭淮河线在地理断点回归中很常用，所以我们使用解析得到的经纬度计算了每家企业距离秦岭淮河线的最短距离，也就是数据集中的 与秦岭淮河线的距离 变量以及 北方或南方，下图展示了 2013 年的数据：

工企业距离秦岭淮河线的距离

是否和省界接触、是否和海岸线接触、是否和陆地国界线接触、否为内部县

这几个变量都是指工企业所处的区县的，可以用于快速筛选工企业的。例如省界，经常也被作为地理断点回归的分界线，假如计算省界附近的工企业距离省界的距离就可以先用 是否和省界接触 变量筛选出来需要的工企业再计算距离，下图展示了河南省省界附近的边界县与工企企业距离省界的距离：
