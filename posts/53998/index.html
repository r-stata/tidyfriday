2000～2014 年工企、海关、上市公司匹配结果

2022-07-26 701 字 约 3 分钟 次阅读 数据资料 企业数据上市公司数据匹配

之前给大家分享了工企和上市公司的匹配结果数据、工企和海关的匹配结果数据以及上市公司和海关的匹配结果数据（超链接为数据介绍，后面的链接为平台上下载数据的链接）：

  1. 上市公司 + 海关：https://rstata.duanshu.com/#/brief/course/42d505c537b74054aa0b268153a21bfa
  2. 工企 + 海关：https://rstata.duanshu.com/#/brief/course/4a1e6a322d40463c99564fe2a4c0ba3f
  3. 工企 + 上市公司：https://rstata.duanshu.com/#/brief/course/274571cddb19436382567af932e9508f

实际上为了方便数据再匹配我把工企、海关、上市公司分别生成了 gqid、hgid、gsid 三个 ID 变量，使用这里 ID 变量可以很方便的进行数据再匹配，例如 工企 + 海关 匹配结果里面有 gqid 和 hgid 变量，而 工企 + 上市公司 匹配结果里面有 gqid 和 gsid 变量，因此可以直接使用 gqid 变量进行再匹配就可以得到 工企 + 海关 + 上市公司 的匹配结果了，也就是我们今天分享的匹配结果。

由于 工企 + 海关 数据的匹配结果中包含完整版和汇总版两份数据，所以这里的 工企 + 海关 + 上市公司 也包含完整版和汇总版两份数据。

🔥 完整版：直接匹配工企和海关数据，结果中的每一个观测值实际上是一条海关数据；

🔥 汇总版：先把海关数据汇总成每个公司每年的进口总额和出口总额（单位：美元），然后再和工企数据进行匹配，结果中的每一个观测值是一条工企数据；没匹配到的公司进口额或者出口额设定为 0；
