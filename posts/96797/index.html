Mac OS 使用技巧及常用软件下载安装教程

2026-03-24 2818 字 约 9 分钟 次阅读 数据资料 编程技巧生活与工具

最近由于 AI agent 的爆火，估计有不少小伙伴从 Windows 更换成了 Mac，作为一位使用了 15 年的老 Mac 用户，今天我给大家分享一些 Mac OS 使用技巧及常用软件下载安装方法。

触控板的使用

不管是购买苹果笔记本（Macbook）还是台式机（Mini、Studio、Pro），都强烈建议不要购买鼠标，因为使用触控板效率更高，特别是选购台式机的时的时候一定要选择触控板而不是鼠标，如果不幸购买了鼠标，一定要立即丢掉，然后再下单一块苹果原厂的触控板，就是下面这种东西：

键盘也一定要坚定的选择苹果原厂的，但凡犹豫一下都是对苹果的不尊重，流畅度是副厂没法比的。副厂的键盘和触控板都会有延迟。

如果是购买了笔记本，就一定不要再额外购买任何鼠标配件了，自带的触控板已经足够使用了。

Mac 系统的触控功能很强大，和 Windows 的使用也有一些差异，也可以使用一些软件定义各种手势操作。常用的我觉得就下面几个：

  • ☝️：单根手指移动 -> 相当于鼠标移动；
  • ☝️：单个手指轻点 -> 没有任何效果；
  • ☝️：单根手指按下去（能感受到反馈）-> 相当于鼠标左键；
  • ☝️：单根手指按住文件/文件夹拖拽 -> 可以移动文件/文件夹，例如把文件拖拽到文件夹里面；也可以拖动应用窗口；
  • ✌️：两根手指上下滑动 -> 可以上下翻文档或者网页；
  • ✌️：两根手指按下去（能感受到反馈）-> 相当于鼠标右键，例如可以新建文件夹等；
  • 👌：三根手指左右滑动 -> 可以把桌面左右切换；
  • 👌：三根手指向上滑动 -> 可以查看应用栏（程序坞，推荐隐藏）以及选择桌面；

  • ️🖖：四根手指放到触控板上向内抓 -> 查看应用面板；
  • ️🖖：四根手指放到触控板上向外张开 -> 关闭应用面板；

除此之外，还可以考虑下载 Bettertouchtool：https://bettertouchtool.cn/ 自定义一些手势操作，例如可以设置四根手指一起点按触控板 -> 关闭当前页面，不过这个是需要付费购买的软件，加上现在也懒得折腾这些，所以现在也没用这个了。

键盘快捷键

键盘快捷键可以大大提升效率，我常用的有下面这些：

  • 选中文件按 Space -> 预览文件；
  • Cmd + Space -> 打开快速搜索窗口（Quicklook）；
  • Cmd + S -> 保存（写代码的时候记得写一行按一次）；
  • Cmd + Delete -> 删除文件/文件夹（选中文件/文件夹）；
  • Cmd + Shift + 3 -> 全屏截图；
  • Cmd + Shift + 4 -> 触控板选择截图窗口;
  • Cmd + Shift + 5 -> 录屏；
  • Cmd + C -> 复制；
  • Cmd + V -> 粘贴；
  • Cmd + X -> 剪切；
  • Cmd + M -> 收起窗口到程序坞；
  • Cmd + A -> 全选；

然后还有一些快捷键是特定软件定义的，不过很多软件都会采用，例如使用 Sublime Text 进行代码编辑的时候可以使用 Cmd + Shift + L 选择多行代码进行编辑。按住 Cmd 可以用触控板选择多个编辑点进行同时编辑，这些可以具体再探索。

另外推荐安装 Alfred 软件，这个软件也会附带一个 Quicklook 窗口（通常是 Option + Space），不过功能更强大。

Alfred：https://www.alfredapp.com/

通过安装 workflows 可以实现很多强大的功能：https://www.alfredapp.com/workflows/

Github 上也可以找到很多好用的 workflows：https://github.com/search?q=alfred+workflows&type=repositories

软件

R 语言

作为分享 R 语言和 Stata 的公众号，当然要先推荐 R 语言和 Stata 了：

R 语言下载：https://cran.r-project.org/

RStudio下载：https://posit.co/

关于 R 语言的详细安装和配置教程，可以学习系列课程 R 语言文本分析的第一次课：https://rstata.duanshu.com/#/course/bf37cf50eef04d38b43541cc52114c96

Stata

Stata 官网：http://stata.com/

这是个商用统计软件，这里就不便分享了。不过下载离线升级包是免费的：

Stata 离线升级包下载：https://www.stata.com/support/updates/

关于 Stata 的详细安装和配置教程，可以学习系列课程 Stata 编程导论的第一次课：https://rstata.duanshu.com/#/course/57571646805e4786b622867cfd5ad1d9

Python

虽然我不讲解 Python 的课程，但是 Python 在很多时候都会用到，特别是现在的 AI agent 会大量调用 Python 工作：

Python 下载：https://www.python.org/

Sublime Text

超好用的轻量化代码编辑器，我非常喜欢是因为这个打开速度超块，几乎无等待，其他的例如 VSCode 打开就会慢一些，让人捉急。下载：https://www.sublimetext.com/download

Terminal（终端）

这个不用安装，电脑自带，很多 Shell 命令都是这里运行的，例如下面说的 homebrew。

官网：https://brew.sh/

AI agent 也会经常用它安装一些命令行工具（Command Line Tools）。

Keka：压缩软件

没有好用的压缩软件，很多文件都难以打开。这里我推荐使用 Keka，这个软件在 App Store 上需要付费购买（38块），但是在官网上可以下载到免费的：

Keka: https://www.keka.io/

豆包

AI 时代自然离不开豆包了：https://www.doubao.com/chat/ 可以下载电脑版，可以解答问题，还附带 AI 浏览器，可以翻译网页、文档。

Ollama

ollama 可以用来部署本地大语言模型：https://ollama.com/

如果想使用本地大模型的 GUI（图形用户界面），也可以安装这个软件（也可以从 App Store安装）：

Enchanted：https://github.com/gluonfield/enchanted

CAJ 文件浏览器：全球学术快报

全球学术快报：https://cajviewer.cnki.net/

这个肯定也是必须了，要不然浏览不了 caj 文件呢。

caj2pdf

caj2pdf：https://github.com/sainnhe/caj2pdf-qt

如果需要进一步处理 caj 文件，就需要先把 caj 转换成 pdf 文件，可以安装上面的工具。

Docker

这里的 Docker 就不是指程序坞了，而是一款专门的软件。

Docker：https://www.docker.com/ 一些软件和程序会需要在 Docker 中运行。

FileZilla：FTP 下载工具

FileZilla：https://filezilla-project.org/

这是一款免费的 FTP 下载工具。例如在下载 国家青藏高原科学数据中心里面的数据就会需要用到，比访达自带的 FTP 下载功能更稳定。

FileZilla：https://filezilla-project.org/

国家青藏高原科学数据中心：https://data.tpdc.ac.cn/home

Calibre：电子书管理软件

Calibre：https://calibre-ebook.com/

除了电子书管理，还可以用于电子书格式转换，例如把一些 epub 格式的电子书转换成 pdf 文件。也是免费的。

Git：版本控制工具

Git：https://git-scm.com/

可以简单粗暴的把它理解成一种上传下载工具，可以从 github、gitee 之类的网站上下载文件，也可以上传文件。

GitHub Desktop

Github 上有非常多的免费资源，我们也可以使用 Github 托管我们的一些文件，不仅仅是代码。这个时候就可以考虑使用 Github Desktop 管理你的项目了：

GitHub Desktop：https://github.com/apps/desktop

自然也是免费的。

XQuartz

XQuartz 项目是一个开源的解决方案，用于实现在 Mac OS X 下运行 X.org 窗口管理系统。不少 R 包的绘图函数需要 XQuartz 的支持，因此提前安装好很有必要。

下载链接：https://github.com/XQuartz/XQuartz/releases/

Github 上的文件下载比较困难，可以借助这个网站快速下载 https://down.npee.cn/

Typora: Markdown 笔记

Typora：http://typora.io/

Markdown 的编辑器非常多，很多代码编辑器也都可以配置成 Markdown 编辑器。所以其实也并不是很推荐 Typora，但是终归是得推荐一个简单容易上手的。其实我自己现在是所有的 Markdown 编辑器都不用了 🤦 平常主要会用 RMarkdown。

这个软件可能需要购买会员，没必要购买，Markdown 的编辑器非常多，免费好用的都一堆。

Adobe Acrobat Reader：PDF 阅读器

Adobe Acrobat Reader：https://get.adobe.com/cn/reader/otherversions

Stata 里面想查看 pdf 帮助文档需要使用 Adobe Acrobat Reader，推荐安装，免费。

Gifox：屏幕录制 gif 生成软件

Gifox：https://gifox.app/

会需要收费，但是免费的足够使用。

WorkBuddy：腾讯出品的 AI 智能体框架

WorkBuddy：https://www.codebuddy.cn/work/

安装即用，最近用的很快乐。可以自动执行用户提出的任务。最近我还用它搭建了一些能够自动根据数据绘制推文图表以及编写推文的 skills。

最近下载安装还能从个人中心领取 5000 积分，每天打开软件还能领取 100 积分（实际没有推广费，但还是希望大家能薅到羊毛）～

QGIS：地理计算软件

QGIS：https://qgis.org/download/

虽然我也不用这个，但是偶尔会用它查看一些数据。开源软件，免费下载。

iphone 镜像

最新的 Mac 系统支持 iphone 镜像功能，不用安装，就是在电脑上可以直接显示和操作手机屏幕：

悄悄的告诉大家，这是个刷短剧的神器，可以直接跳过广告（估计是软件的 bug）。

与 IPad 或者其他 Mac 电脑联动

不同苹果电脑（包括 Pad）可以通过链接功用一套键鼠，也就是光标可以在各个设备直接直接移动，非常高效率。另外也可以外接显示器作为单独桌面而不是只显示一个桌面。

App Store 上的应用

其他的就不必多说了，直接从 AppStore 上下载即可，例如微信、抖音、迅雷、迅雷影音、网易云音乐、汽水音乐等。
